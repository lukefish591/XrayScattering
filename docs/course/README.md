# Intro course exercises

Teaching toys for the self-paced course. **Not** production models and **not** experimental data.

Index: [`../intro-course.md`](../intro-course.md)

From `xray-scattering/` (venv on):

```bash
source .venv/bin/activate
cd course
python 01_kinematics.py
python 02_fresnel.py
python 03_specular_vs_diffuse.py
python 04_dwba_yoneda.py
python 05_self_affine.py
python 06_islands.py
python 07_kiessig.py
python 08_print_plan.py
```
