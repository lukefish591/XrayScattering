# Experimental data

Place measured datasets here when they are available. Nothing in this folder is committed except this README.

When you add data, also add a short note (filename, instrument, date, units, and any reduction already applied) in `docs/context/` so models can be compared against a documented measurement.

Typical formats this environment already supports reading: HDF5/NeXus (via h5py), CSV, and NumPy arrays.
